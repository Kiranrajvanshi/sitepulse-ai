About SitePulse AI

A production-grade, developer-oriented website health analyzer engineered to provide clear, actionable visibility into website performance, search engine readiness, accessibility compliance, and Core Web Vitals.

What SitePulse AI Does

SitePulse AI simulates real-world browser loading conditions and conducts rigorous static and runtime audits on any public URL. Rather than delivering abstract or artificially inflated "vanity metrics," SitePulse translates raw technical telemetry into four foundational pillars:

Performance Payload efficiency, server response times (TTFB), and render-blocking resources.
SEO Quality Title, meta description, heading structure, canonical tags, robots.txt, and sitemaps.
Accessibility WCAG 2.1 AA conformance: color contrast ratios, alt text, and semantic ARIA landmarks.
Best Practices HTTPS enforcement, modern image formats (AVIF/WebP), HSTS, and valid HTML doctype.

How The Audit Engine Works

SitePulse AI combines two analytical layers to produce reliable diagnostics:

  1. Direct Server Probe: The backend initiates an HTTP request directly to the target host to measure real Time to First Byte (TTFB), verify SSL/TLS certificate validity, inspect server compression (Brotli/Gzip), verify HTTP headers (HSTS, CSP), and parse HTML elements like title length, meta description, heading hierarchy, and image alt tags.
  2. Google PageSpeed Insights API: The backend queries Google's official PageSpeed Insights REST API running on Google Lighthouse v11+. This generates lab simulation benchmarks for Core Web Vitals including Largest Contentful Paint (LCP), Interaction to Next Paint (INP), Cumulative Layout Shift (CLS), and First Contentful Paint (FCP).

Live Analysis vs. Demo Mode

Integrity is a core principle of SitePulse AI. The platform never fabricates or presents synthetic mock data as live telemetry:

Capability Live Analysis Mode Demo Mode
API Key Requirement Configured PAGESPEED_API_KEY in .env (or free public quota) No API key needed (works out-of-the-box)
Core Web Vitals Real Google Lighthouse lab/field measurements Realistic deterministic domain-based sample data
Direct DOM & SSL Check Active real-time probe against target domain Active direct probe enriched with sample audits
Report Disclosure Labeled with Verified Live Clearly marked with Demo Mode banner

Technology Stack

SitePulse AI was intentionally engineered without complex SPA frameworks (React, Next.js, or Tailwind CSS) to highlight clean foundational web standards, readability, and solid backend architectural design:

Backend Framework Python 3 & Flask
Database Layer SQLite 3 (Parameterized)
Frontend UI HTML5, CSS3, Bootstrap 5
Data Visualizations Chart.js (Radar Benchmarks)
Production Server Gunicorn WSGI
External Auditing API Google PageSpeed Insights v5
